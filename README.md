The initial goal of this project is to make a more efficient parking space and simulate how vehicles would navigate through a filled multi-lane parking space to find the nearest spot without wasting any time by roaming to find an open spot that has appropriate space for their vehicle. The project would help reduce the time taken by people to navigate to an empty parking spot, and also reduce the carbon emissions caused by reducing the fuel consumed in travelling to an empty parking spot.

The project would be able to show how different layouts of the parking model would work for different random vehicles, and would generate a parking ticket or fee for parking based on the type of vehicle that is parked (based on space required by the vehicle/EV charging support required, etc) and display it and store it for the admin of the parking lot.
